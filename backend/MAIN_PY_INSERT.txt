STEP 9: main.py change

1. Add this import near your other router imports:

from app.routers.recovery import router as recovery_router
from app.models.recovery_otp import RecoveryOTP

2. Add this after the other app.include_router(...) calls:

app.include_router(recovery_router)

Because the RecoveryOTP model imports Base, it will be included when your existing startup already runs Base.metadata.create_all(bind=engine).

If your main.py does not import all models before create_all, add:

from app.models.recovery_otp import RecoveryOTP

before create_all runs.
